# Varidhi - Luxury Island Tour Packages

Varidhi is a frontend web project offering curated 15-day luxury island tour packages for groups of 5 or more travelers across 10 handpicked worldwide islands.

## Project Highlights
- **10 Curated Islands**: Bora Bora, Maldives, Santorini, Bali, Maui, Seychelles, Galápagos, Capri, Palawan, and Fiji.
- **Group Package Constraint**: Minimum group size of 5 travelers.
- **Payment Structure**: 25% advance booking fee, 75% payable on arrival.
- **Automated Itinerary Generation**: Immediate 15-day personalized trip itinerary and printable voucher upon simulated payment confirmation.
- **Technology Stack**: Pure HTML5, CSS3, and modern Vanilla JavaScript (zero backend dependencies).
