BOOKSHELL — BOOKSTORE E-COMMERCE WEBSITE
========================================

FILES
- index.html  : page structure
- style.css   : design, layout, responsive mobile styles
- script.js   : book catalogue, search, filters, sorting, wishlist and cart

HOW TO RUN
1. Extract the ZIP file.
2. Keep all three files in the same folder.
3. Double-click index.html, or open it in Chrome/Edge.
4. For editing, open the folder in VS Code or Dev-C++ is not suitable for HTML.

FEATURES TO SHOW IN YOUR PRESENTATION
- Responsive bookstore landing page
- Category cards and category filters
- Search books by title, author, or category
- Sort by price or rating
- Add books to cart, increase/decrease quantity, remove items
- Wishlist hearts and saved-book view
- Checkout demo modal with order total
- Newsletter form interaction
- Mobile navigation and toast notifications

NOTE
This is a front-end demonstration. It does not use a real database, user login,
payment gateway, or order backend. Book covers are designed with CSS, so the site
does not depend on external book-cover image files. Google Fonts are optional and
need an internet connection; fallback fonts are included.
