    How CivicFix Works

    Three simple steps in this prototype.

    1. 1

      Spot and describe

      Write a short title and description of the problem you noticed.

    2. 2

      Add location and severity

      Tell us the area, an optional landmark, how serious it is, and optionally add a photo.

    3. 3

      Track and support

      Your report is saved only in this browser, where you can view it and support other sample issues.

    About this project

    CivicFix is a frontend-only student portfolio prototype built with HTML, CSS and vanilla JavaScript.

    Prototype notice: CivicFix is not an official government portal. Reports are not sent to any authority, nothing is verified, and all sample data is fictional.
